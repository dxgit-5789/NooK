# NooK v1.0.0 - Initial Release

**Release Date:** August 8, 2026

## About This Release

NooK is a beautiful, fast, and completely offline desktop text editor for Windows. Built with privacy in mind, NooK keeps all your notes and documents stored locally on your computer—no cloud, no accounts, no internet required.

## What's Included

This release includes a fully-featured text editor with:

- **Beautiful Material 3 Design** - Modern UI with light/dark themes and smooth animations
- **Powerful Text Editing** - Distraction-free writing with autosave, find/replace, undo/redo, and zoom controls
- **Lightning-Fast Search** - Instantly search across all your documents by title, filename, or content
- **Smart Organization** - Pin important documents, mark favorites, and manage everything with an intuitive interface
- **Complete Privacy** - 100% offline operation, all data stays on your computer
- **Flexible Workspace** - Choose any folder as your workspace, with automatic organization of documents, trash, and settings

## Installation

1. Download `nook.exe` from this release
2. Run the executable - no installation required
3. Choose a workspace folder on first launch
4. Start writing!

## System Requirements

- Windows 10 or later
- 100 MB disk space + space for your documents
- 256 MB RAM minimum (512 MB recommended)

## Getting Started

After launching NooK:
1. Select a workspace directory where your notes will be stored
2. Click "New Document" to create your first note
3. Start typing - the first line becomes your document title
4. Documents auto-save every 30 seconds

## Known Limitations

- Only supports plain text (.txt) files
- Windows-only (macOS and Linux support possible in future)
- No markdown rendering (plain text only)
- Single workspace at a time

## Future Enhancements

We're considering features like markdown support, multiple workspaces, file encryption, and rich text formatting for future releases.
